Error Interno del Servidor
El Error 500 (Internal Server Error) es un código de estado genérico que indica que el servidor web encontró un fallo inesperado y no pudo completar la solicitud. Como es un problema del lado del servidor, el fallo no proviene de tu dispositivo o conexión, lo cual sucede típicamente cuando se detecta que la base de datos está apagada o inaccesible.
🔌

Base de Datos no Disponible

El servidor detectó que la base de datos (MySQL) está apagada o inaccesible. Por favor, inicia el servicio de MySQL en el panel de control de XAMPP.
